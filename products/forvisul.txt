CRITICAL FIX #2: PROFIT_FREQUENCY (was 0% accuracy → target 85%+)
═══════════════════════════════════════════════════════════════════════════════════════════════════

IMPORTANT: Distinguish between PAYMENT FREQUENCY and PROFIT FREQUENCY

PAYMENT FREQUENCY: How often customer PAYS premiums/contributions
  ├─ Annual (once per year)
  ├─ Semi-Annual (twice per year)
  ├─ Quarterly (4 times per year)
  └─ Monthly (12 times per year)
  Example: "The contributions can be made on Annual, Semi-Annual or Quarterly basis"

PROFIT FREQUENCY: How often PROFIT/RETURN is CREDITED to customer
  ├─ Monthly (profit credited monthly)
  ├─ Quarterly (profit credited quarterly)
  ├─ Semi-annual (profit credited twice per year)
  ├─ Annual (profit credited once per year)
  ├─ At Maturity (profit credited when plan matures)
  └─ N/A (no profit, e.g., health insurance)

DEFAULT RULES FOR TAKAFUL SAVINGS PLANS:
  ├─ If product is savings/investment-linked plan → DEFAULT = "At Maturity"
  ├─ If product is health insurance → "N/A"
  └─ If product is protection/debit card → "N/A"

EXTRACTION DECISION TREE:

Step 1: Check if health/protection insurance
  └─ If yes → PROFIT_FREQUENCY = "N/A" (insurance doesn't have profit frequency)

Step 2: Check for explicit profit frequency mentions
  ├─ If text says "profit paid at maturity" → "At Maturity"
  ├─ If text says "profit at end of term" → "At Maturity"
  ├─ If text says "annual profit" → "Annual"
  ├─ If text says "monthly profit" → "Monthly"
  └─ If text says "profit on quarterly basis" → "Quarterly"

Step 3: If no explicit mention found AND product is savings/investment-linked
  └─ DEFAULT → "At Maturity"

CRITICAL: Do NOT confuse "Payment Frequency" with "Profit Frequency"
  ❌ WRONG: Payment says "Annual, Semi-Annual, Quarterly" so PROFIT_FREQUENCY = "Annual"
  ✓ CORRECT: Payment frequency ≠ Profit frequency. For savings plans default to "At Maturity"

EXAMPLES:

Document 1 (Danish Education Plan):
  Text: "Payment Frequency: Annual, Semi-Annual or Quarterly basis"
  Rule: This is PAYMENT frequency, not profit. Plan is savings-linked
  OUTPUT: PROFIT_FREQUENCY = "At Maturity"

Document 3 (Shifa Health Plan):
  Text: "Year renewal plan" (health insurance)
  Rule: Health insurance has no profit frequency
  OUTPUT: PROFIT_FREQUENCY = "N/A"

Document 7 (Zindagi Premier):
  Text: "savings and protection plan...Vitality wellness program"
  Rule: Savings plan, no explicit profit frequency mentioned
  OUTPUT: PROFIT_FREQUENCY = "At Maturity"

FORMAT: Monthly | Quarterly | Semi-annual | Annual | At Maturity | N/A

CRITICAL FIX #6: PROFIT_TYPE (was 22% accuracy → target 80%+)
═══════════════════════════════════════════════════════════════════════════════════════════════════

UNDERSTANDING:
  PROFIT_TYPE describes HOW profit/return varies:
  ├─ "Variable" = Return depends on market/fund performance (most common for unit-linked)
  ├─ "Tier-based" = Different profit rates for different term lengths or contribution amounts
  ├─ "Fixed" = Guaranteed fixed profit rate
  ├─ "Bonus-based" = Bonus structure
  ├─ "Bonus-based & Unit-linked" = Hybrid (use exact phrase)
  └─ "N/A" = No profit (health insurance, protection plans)

DECISION TREE:

Step 1: Check product type
  ├─ If health insurance → "N/A"
  ├─ If debit card protection (Zaamin) → "N/A"
  └─ Otherwise continue to Step 2

Step 2: Look for unit-linked language
  ├─ If mentions "Unit Allocation", "fund selection", "investment funds", "PIA" → "Variable"
  ├─ If mentions "customer can select...units in chosen funds" → "Variable"
  └─ Otherwise continue to Step 3

Step 3: Look for tier/rate structure
  ├─ If shows different rates by term (e.g., "Year 1: 60%, Year 2: 80%") → "Tier-based"
  ├─ If shows different rates by contribution level → "Tier-based"
  └─ Otherwise continue to Step 4

Step 4: Look for bonus language
  ├─ If mentions "bonus" + "unit-linked" → "Bonus-based & Unit-linked"
  ├─ If mentions only "bonus structure" → "Bonus-based"
  └─ Otherwise continue to Step 5

Step 5: Default
  ├─ If savings/investment plan but no specific profit structure → "Variable"
  └─ Otherwise → "N/A"

CRITICAL CLARIFICATION:
  "Unit-linked" is a MECHANISM (customer's money linked to fund performance)
  "Variable" is the PROFIT_TYPE (return varies with market)
  
  So if document mentions "Unit Allocation" or "fund selection" → PROFIT_TYPE = "Variable"

EXAMPLES:

Document 1 (Danish): Mentions "Unit Allocation...buy units in chosen funds" → "Variable"
Document 2 (Saholat): Mentions "Unit Allocation...funds" → "Variable"
Document 3 (Shifa): Health insurance → "N/A"
Document 4 (Tadbeer): Mentions "Unit Allocation" → "Variable" (not "Unit-linked")
Document 5 (Uroos): Mentions "Unit Allocation" → "Variable"
Document 6 (Zeenat): Mentions "Unit Allocation" → "Variable"
Document 7 (Zindagi): Mentions "Tier-based allocation" + "Vitality" → "Variable" (primarily market-linked)
Document 8 (Jubilee): Shows allocation percentages by year (60%, 80%, 95%, 100%) → "Tier-based"
Document 9 (SLIC): Shows "Bonus-Based and Unit Linked" hybrid → "Bonus-based & Unit-linked"

FORMAT: Variable | Tier-based | Fixed | Bonus-based | Bonus-based & Unit-linked | N/A
