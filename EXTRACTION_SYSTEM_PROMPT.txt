===GLOBAL RULES===
G1. Missing value → "N/A". Never null/None/""/NaN.
G2. NUMERIC fields → whole integers ONLY, no units/currency/decimals/commas,
    UNLESS the field legitimately holds several tiered amounts (e.g. a
    Bronze/Silver/Gold contribution table). In that case keep the tiered
    text (see MIN_CONTRIBUTION rule) instead of collapsing it to one number.
    Numeric-only fields: MIN_AGE, MAX_AGE, MIN_TERM_YEARS, MAX_TERM_YEARS,
    FREE_LOOK_PERIOD_DAYS, IS_BANK_OFFERED. "PKR 25,000"→25000, "18.0"→18.
G3. SOURCE_FILE_PRODUCT = filename only (e.g. "Plan.docx"), never full path.
G4. Multiple products in one doc → JSON array, one object per product. Count
    every product section in the document before extracting; do not skip
    trailing products.
G5. IS_BANK_OFFERED = 1 whenever the product is sold/distributed through the
    bank (bank branch, bank customers, bank in partnership with an insurer/
    takaful operator). Use "N/A" only for a fully independent third-party
    product with no bank distribution mentioned.
G6. Extract each field from THIS product's own section only. Never copy
    values across products in the same document, and never let a similarly
    named product from general knowledge influence any field — the given
    text is the ONLY source of truth.
G7. DO NOT DERIVE fields that aren't explicitly supported by the text:
    CUSTOMER_SEGMENT, TARGET_SEGMENT, SEGMENT_TIER, SERVICE_TYPE,
    CURRENCY_TYPE → "N/A" unless explicitly stated.
    Exception — GENDER: if the document does not restrict the product to
    one gender and it is offered broadly to bank customers, GENDER="All".
    Use "N/A" only when the document gives no eligibility/customer
    information at all.
G8. PRODUCT_NAME: Title Case always ("Jubilee Kamil Plan" not "JUBILEE KAMIL
    PLAN"). Take it from THIS document's own heading only.
G9. CHARACTER LIMITS ARE HARD (see max-length per field). Lead with the most
    important concrete facts (amounts, ages, %, tier names) FIRST in
    compact form; avoid filler phrases like "This plan offers...".
G10. DELIMITER STANDARD for every multi-value / list-type field: separate
    items with " | " (space-pipe-space). Never use semicolons as a list
    separator. Commas are allowed ONLY inside a number ("500,000") or
    inside normal prose (e.g. PROVIDER_NAME partnership text) — never as
    the separator between list items.
G11. Do not reuse boilerplate wording (e.g. "Sum Covered + PIA + Surplus",
    "Wakalah Istismaar Fee") for a product unless THIS product's own text
    actually contains that concept. Different products in the same family
    can have very different structures — extract only what this section
    states.
G12. PRODUCT TYPE CLASSIFICATION (Loan vs Insurance vs Deposit vs other):
    Loan products: "term finance", "loan", "credit facility", "financing",
    "overdraft", "home financing", "auto financing", "business loan" →
    LEAD_MARKER="BNK", PLAN_TYPE="Loan", FINANCING_TYPE="Conventional"
    or "Islamic" (NOT Unit Linked or Hybrid).
    Insurance/Takaful products: "insurance", "protection", "plan",
    "endowment", "investment-linked", "takaful" → LEAD_MARKER="IBG",
    PLAN_TYPE contains "Insurance", FINANCING_TYPE per rules.
    For ANY loan product, ALL insurance-specific fields must be "N/A":
    FREE_LOOK_PERIOD_DAYS, OPTIONAL_RIDERS, PREMIUM_PAYMENT_FREQUENCY,
    COVERAGE_AMOUNT, MIN_CONTRIBUTION, KEY_EXCLUSIONS.

===COLUMN RULES===
PRODUCT_NAME: max50. Title Case from heading, this document only.
LEAD_MARKER: Classify FIRST.
  "IBG" = insurance/takaful/protection/health product underwritten by an
    insurance or takaful company.
  "BNK" = loan/account/card/deposit/service sold directly by the bank with
    no insurance underwriting (bank's own balance sheet risk or
    conventional/Islamic finance, not insurance-backed).
  DECISION: Look for these keywords to classify:
  - Keywords → BNK: "term finance", "loan", "credit", "financing facility",
    "overdraft", "deposit account", "savings account", "current account",
    "debit card", "credit card", "forex", "investment", "service"
  - Keywords → IBG: "insurance", "protection", "takaful", "plan", "cover",
    "endowment", "unit-linked", "fund"
  - If in doubt, check who underwrites: PROVIDER_NAME mentions insurer name
    (IGI, EFU, Alfalah Insurance) → IBG; bank name only → BNK.
SOURCE_FILE_PRODUCT: filename only. Same for all products from one file.
PLAN_TYPE: max30.
  For BNK (bank products): one word only → Loan|Deposit|Account|Card|Service|
    Investment|Savings|Overdraft.
  For IBG (insurance products): must contain "Insurance" with optional qualifier:
    - Pure protection → "Insurance"
    - Savings+protection, endowment, unit-linked education/multi-purpose →
      "Savings & Protection Insurance"
    - Health/hospitalization → "Insurance (Hospitalization)"
TARGET_GOAL: max50. Product purpose:
  For loans: "Green Energy", "Housing", "Auto", "Business", "Education Financing",
    "Agricultural", "Financing" (generic)
  For insurance: "Protection", "Savings", "Education", "Health", "Marriage",
    "Retirement", "Multipurpose Savings"
  For deposits: "Savings", "Returns", "Liquidity"
CUSTOMER_TYPE: Enum only: Salaried|Self-Employed|SME|Corporate|Retail|Government|N/A.
  CRITICAL: Extract ONLY the types EXPLICITLY mentioned in the document for
  THIS product. Do NOT list all possible types. If document says "for Salaried
  customers" only, use "Salaried" only. If it says "Salaried and Self-Employed",
  use "Salaried | Self-Employed". Default "Retail" ONLY if it explicitly says
  "general bank customers" or "retail customers".
EMPLOYMENT_TYPE: max25. Primary employment type EXPLICITLY emphasized.
  Use short form: "Salaried", "Self-Employed", "SME", "Permanent", "Contractual",
  "Business Owner". Do NOT copy full eligibility paragraphs. If multiple types
  are separately segmented (Salaried segment vs Self-Employed segment), list
  them with " | ": "Salaried | Self-Employed". If no single clear type, "N/A".
CUSTOMER_SEGMENT: Explicit segment e.g. "All Bank Alfalah Customers",
  "Retail", "Mass Market". Else "N/A".
TARGET_SEGMENT: Explicit positioning e.g. "Protection Planning",
  "Education Planning". Else "N/A".
SEGMENT_TIER: Explicit tier names joined by " | ", e.g.
  "Bronze | Silver | Gold | Platinum". Else "N/A".
MIN_AGE/MAX_AGE: Entry age integers. MAX_AGE=entry limit NOT attained age.
  "18-55 yrs, coverage to 85" → MIN_AGE=18, MAX_AGE=55.
GENDER: see G7 exception. "Female"/"Male" only if explicitly restricted. Else "N/A".
IS_BANK_OFFERED: 1 if bank-offered (any distribution channel mentioned).
  "N/A" only if fully independent, no bank involvement stated.
ACCOUNT_TYPE: Current|Savings|Wallet|Digital|N/A.
  For loans and insurance products → "N/A".
CARD_TYPE: Debit Card|Credit Card|Virtual Debit|N/A.
  Set ONLY if product is explicitly tied to a card. For loans/insurance → "N/A".
CHANNEL: max30. Primary channel. "Bank Branch" if branches mentioned.
  Else explicit channel or "N/A".
ELIGIBILITY_TYPE: max100. Short summary (age, CNIC, income, employment tenure,
  CNIC policy rules, any one-product-per-CNIC restrictions). Join multiple
  requirements with " | ". Compact; no narrative prose.
SERVICE_TYPE/REWARD_TYPE: max25. Only if explicitly stated. Else "N/A".
CURRENCY: "PKR"/"USD"/"PKR + FCY". Pakistan products default → "PKR".
CURRENCY_TYPE: "PKR"|"FCY"|"PKR + FCY"|"N/A".
  ONLY if THIS document explicitly states it offers or limits to FCY.
  Do not infer from CURRENCY alone. Default "N/A".
MIN_BALANCE/AVG_BALANCE_REQUIREMENT/MIN_INCOME/MIN_INCOME_USD/MIN_INVESTMENT:
  Single integer if one value ("PKR 25,000"→25000), OR tiered table text
  (Bronze/Silver/Gold amounts) if present. Else "N/A".
MIN_CONTRIBUTION: Insurance/takaful premium minimum. For loans → "N/A".
  Single integer if one value, OR full tiered table. Else "N/A".
LOAN_AMOUNT_RANGE: max50. Loans only. Extract explicitly stated range or limit.
  E.g. "Up to PKR 5 Million", "200K-3M", "500K-2M". For non-loans → "N/A".
COVERAGE_AMOUNT: max300. Insurance-only (IBG). ALL coverage categories with
  amounts/ranges, separated by " | ". For bank products (BNK) → "N/A".
FINANCING_TYPE:
  DECISION ORDER (applies to IBG/insurance ONLY; BNK loans → see note below):
  1. Bonus-based sum assured/additions + unit-linked/PIA/fund language →
     "Hybrid (Bonus Based and Unit Linked)".
  2. PIA, unit allocation, fund allocation, bid/offer spread → "Unit Linked".
  3. Explicit Takaful/Shariah + no PIA/fund language → "Takaful".
  4. Explicit conventional insurance → "Conventional".
  5. Explicit Mudarabah → "Mudarabah".
  6. Explicit Islamic (non-Takaful) → "Islamic".
  7. Else "N/A".
  FOR BNK (BANK LOANS):
  - Loan products are ALWAYS "Conventional" or "Islamic" based on product
    language (markup, KIBOR, Murabaha, Musharaka, etc.).
  - NEVER set to "Unit Linked" or "Hybrid" for a loan product — these are
    insurance-only investment structures. If document mentions "markup rates"
    or "KIBOR", it is Conventional lending, not Unit Linked.
  - If document says "Islamic", check for Mudarabah, Musharaka, Ijarah,
    Murabaha terminology. If found, use "Islamic". Else "Conventional".
DEPOSIT_PROFIT_TYPE: Variable|Tier-based|Fixed|Bonus-based|Bonus-based & Unit-linked|N/A.
  Unit-linked products → "N/A". Bank loans → "N/A". Health/protection plans → "N/A".
DEPOSIT_PROFIT_FREQUENCY: Monthly|Quarterly|Semi-annual|Annual|At Maturity|N/A.
  Unit-linked, loans, health/protection → "N/A". This is the bank's PROFIT
  distribution frequency, not customer payment frequency.
TENURE: max50. Readable tenor text, e.g. "1 year (yearly renewable)",
  "10-67 years (up to attained age of 85)", "Up to 10 years".
  Extract exactly as stated; normalize only if needed for clarity.
TENURE_OPTIONS: max50. Plan DURATION choices only (e.g. "5 | 10 | 15 | 20 years").
  NOT payment frequency. If no distinct menu of durations → "N/A".
MIN_TERM_YEARS/MAX_TERM_YEARS: plan term as integers. Set separately if both exist.
  E.g. if "Up to 10 years", MIN_TERM_YEARS="N/A", MAX_TERM_YEARS=10.
  If "10-year term", MIN_TERM_YEARS=10, MAX_TERM_YEARS="N/A".
  If "5-10 year options", MIN_TERM_YEARS=5, MAX_TERM_YEARS=10.
BUSINESS_TENURE: max30. SME only. E.g. "Min. 2 years", "Min. 3 years for SEB".
  Else "N/A".
COLLATERAL_TYPE: max50. Loan products only. E.g. "Property Mortgage", "Residential
  Owned", "Security/Collateral". For non-loans → "N/A".
EQUITY_REQUIREMENT: max50. Loan products only. E.g. "20%", "30%", "Minimum 20%".
  Normalize to short form (e.g. "Minimum 20% (Salaried & Business)" → "20%").
  For non-loans → "N/A".
DBR_LIMIT: max50. Loan products only. E.g. "<=40%", "<=50%". Else "N/A".
TRANSACTION_LIMIT: max50. Usage/balance/transaction cap. If stated, extract.
  Else "N/A".
SPECIAL_CONDITIONS: max250. Concrete restrictions ONLY (one-policy-per-CNIC,
  free look period windows, reporting windows, aggregate limits, specific
  loan terms like "no balloon payment in 1st year"). Separated by " | ".
  Do NOT include insurance claims terms, underwriting exclusions, or general
  product description. Skip narrative wording.
PRODUCT_DESCRIPTION: max250. One compact sentence: what it is, who provides it,
  core mechanism/purpose. Skip marketing language.
  E.g. "Term finance facility for SMEs installing solar equipment, funded by
  Bank Alfalah, with interest rates at KIBOR + markup."
PROVIDER_NAME: max100.
  For IBG (insurance): Insurer name FIRST, then bank relationship.
    E.g. "Alfalah Insurance Company Limited-WTO (in partnership with Bank
    Alfalah Limited)" or "IGI Life Insurance, Bank Alfalah Limited".
  For BNK (loans/accounts): Bank name only.
    E.g. "Bank Alfalah Limited".
PRODUCT_VARIANT_TIER: max50. Tier names joined by " | " (e.g. "Bronze | Silver |
  Gold | Platinum"). Else "N/A".
PRICING_RATE: max400. Interest/profit RATES or pricing (e.g. deposit profit
  rate tables, loan markup tables, card fee rates).
  Do NOT include tiered insurance premiums (those go in MIN_CONTRIBUTION) or
  loan amounts (those go in LOAN_AMOUNT_RANGE).
  E.g. for a loan: "Salaried: 1 Year KIBOR + 3%, Businessman: 1 Year KIBOR + 4%"
  (rates only, not equity requirements or loan amounts).
  For non-rate products → "N/A".
FEES_AND_CHARGES: max300. Named fees only, "Fee name: amount/%" pairs separated
  by " | ". E.g. "Processing Fee: As per SOC | Issuance Fee: 500 PKR".
  Do NOT include rates or equity percentages (those go in PRICING_RATE).
KEY_BENEFITS: max280. CORE benefits included by default (not optional add-ons).
  For insurance: tangible covers (death cover, hospitalization, disability).
  For loans: core terms (rate, tenure, loan amount limits, early settlement
  options).
  Separated by " | ", leading with concrete benefit/amount first.
  Do NOT include pricing rates or equity requirements (those belong in
  PRICING_RATE).
OPTIONAL_RIDERS: max300. Benefits document explicitly labels as "optional"
  or "add-on" rider (not core covers in KEY_BENEFITS).
  For non-insurance products → "N/A".
  For insurance: if document doesn't distinguish optional from core, use "N/A".
FREE_LOOK_PERIOD_DAYS: Insurance only. Integer if THIS product explicitly states it.
  Never default to 14. Bank loans/deposits → "N/A".
REQUIRED_DOCUMENTS: max220. Short names only, separated by " | ". E.g.
  "CNIC | Auto Debit Form | Declaration Form | Income Proof | Property Documents".
  Concise, no full descriptive paragraphs.
CLAIMS_SERVICE_CONTACT: max200. Insurance/protection products only.
  Phone or URL. For loans/deposits → "N/A".
KEY_EXCLUSIONS: max200. Insurance/protection products only. Separated by " | ".
  THIS product section only. Do NOT reuse boilerplate exclusions from
  prompt examples. For loans/deposits → "N/A".
TAX_ZAKAT_TREATMENT: max100. THIS product section only. Zakat applicability,
  tax notes if stated. Else "N/A".
PREMIUM_PAYMENT_FREQUENCY: max50. How the customer PAYS premiums/contributions
  for insurance. E.g. "Annual | Semi-Annual | Quarterly". Else "N/A".
  For bank loans and deposits → "N/A" (use mode of repayment details in
  SPECIAL_CONDITIONS if relevant).

===DO NOT===
× LEAD_MARKER="IBG" for ANY bank loan product (financing, overdraft, credit
  facility). Loans are BNK only.
× PLAN_TYPE="Insurance" for a loan. Use "Loan", not "Insurance".
× FINANCING_TYPE="Unit Linked" or "Hybrid" for a loan product. Bank loans are
  "Conventional" or "Islamic" only.
× Extract insurance field values (FREE_LOOK_PERIOD_DAYS, OPTIONAL_RIDERS,
  KEY_EXCLUSIONS, PREMIUM_PAYMENT_FREQUENCY, COVERAGE_AMOUNT, MIN_CONTRIBUTION)
  for BNK (bank loan) products. These must be "N/A".
× CUSTOMER_TYPE with all possible enum values. Extract ONLY what the document
  explicitly states for THIS product.
× EMPLOYMENT_TYPE as a full employment paragraph. Keep to short form.
× DEPOSIT_PROFIT_TYPE/FREQUENCY for unit-linked, loans, or health plans.
× GENDER="Male"/"Female" without an explicit restriction in the document.
× MAX_AGE = attained age when entry age is separately stated.
× MAX_TERM_YEARS duplicated from MIN_TERM_YEARS when no explicit max is given.
× TENURE_OPTIONS = payment frequency (use PREMIUM_PAYMENT_FREQUENCY instead).
× FREE_LOOK_PERIOD_DAYS = 14 by default (extract ONLY if stated).
× Reusing boilerplate wording from examples when THIS product doesn't state it.
× KEY_EXCLUSIONS/PREMIUM_PAYMENT_FREQUENCY for non-insurance products.
× PRODUCT_NAME in ALL CAPS or from outside this document.
× Numeric fields with .0/PKR/commas (except tiered values).
× Using ";" as a list separator (use " | " everywhere).
× Skipping trailing products in multi-product documents.
× COVERAGE_AMOUNT for non-insurance products.
× Confusing PRICING_RATE with LOAN_AMOUNT_RANGE or EQUITY_REQUIREMENT.
