CORE EXTRACTION RULES
================================================================================

If field not in document → use "N/A" (string, not null)
All numeric fields → NUMBERS ONLY (no currency, no text)
No invented data → reference document only
Character limits are HARD LIMITS → truncate if exceeded

================================================================================
COLUMN DEFINITIONS & EXTRACTION RULES
================================================================================

1. PRODUCT_NAME
   Max 50 chars | Example: "Alfalah Car Ijarah"
   Normalized product name, trim extra spaces

2. LEAD_MARKER
   IBG (Insurance/Takaful) | BNK (Bank)
   If insurance/takaful/protection/endowment → IBG | Otherwise → BNK

3. SOURCE_FILE_PRODUCT
   Just filename (e.g., "Danish_Education_Plan.docx"), no full path

4. PLAN_TYPE
   ONE word only: Insurance | Savings | Deposit | Loan | Card | Investment | Service | Loyalty

5. TARGET_GOAL
   Single value (max 30 chars): Protection | Education | Health | Savings | Marriage | 
   Housing | Investment | Retirement | Wellness | General
   
   DECISION: Check PRODUCT_NAME FIRST for keywords:
   ├─ If name has "Education" → Education
   ├─ If name has "Marriage"/"Uroos" → Marriage
   ├─ If name has "Shifa"/"Health" → Health
   ├─ If name has "Zindagi"+"Vitality" → Savings (wellness captured in SEGMENT)
   ├─ If name has specific goal → Use that goal
   └─ Else use description/purpose from document

6. CUSTOMER_TYPE
   ONE value only: Salaried | Self-Employed | SME | Corporate | Retail | Government | N/A
   
   RULE: If multiple in document, pick PRIMARY (first/most common)
   NEVER comma-separated lists

7. EMPLOYMENT_TYPE
   ONE value: Salaried | Self-Employed | Government | Military | N/A
   
   EXTRACTION: Look in "Target Market" section FIRST, then "Eligibility Criteria"
   ├─ "Salaried Individuals" / "Professionals" → Salaried
   ├─ "Self Employed" / "Proprietorship" / "Partners" → Self-Employed
   ├─ "Government" / "Armed Forces" → Government
   └─ Not mentioned or only general audience → N/A

8. CUSTOMER_SEGMENT
   Short description (max 50 chars): "All Bank Customers", "Salaried Professionals", 
   "Female & Spouse", "SME Business Owners", etc. | N/A if not mentioned

9. TARGET_SEGMENT
   More specific segment (max 50 chars): "Education Planning", "Healthcare Coverage", 
   "Multipurpose Planning", "Marriage Planning", "Wellness Focused" | N/A if not mentioned

10. SEGMENT_TIER
    ONE value: Mass Market | Retail | Premium | Niche
    
    DECISION TREE (apply in order):
    ├─ If GENDER = "Female" only → Niche
    ├─ If MIN_CONTRIBUTION >= 250000 → Premium
    ├─ If TARGET_GOAL = "Health" AND open to all → Mass Market
    └─ Else → Retail
    
    Note: "Niche" should be RARE (only gender/specialty products)

11. MIN_AGE
    Number only | Extract from "age" patterns | N/A if not found

12. MAX_AGE
    Number only | Extract maximum age from eligibility | N/A if not found

13. GENDER
    EXACTLY: "All" | "Male" | "Female" | "N/A" (NOT "ALL", "all", "MALE", etc.)
    
    ├─ If female-only product (title/eligibility) → Female
    ├─ If male-only product → Male
    ├─ Otherwise → All
    └─ No gender mention → All

14. IS_BANK_OFFERED
    1 if requires bank customer status | N/A otherwise

15. ACCOUNT_TYPE
    Current | Savings | Wallet | Digital | N/A (for non-bank products)

16. CARD_TYPE
    Debit | Credit | Virtual Debit | Premium | N/A (for non-card products)

17. CHANNEL
    Max 30 chars: "Bank Branch", "Mobile App", "Online", "Call Center", "Direct" | N/A

18. ELIGIBILITY_TYPE
    Max 50 chars: Brief eligibility summary (e.g., "Bank Alfalah customer + CNIC")

19. SERVICE_TYPE
    Max 30 chars | Derived from TARGET_GOAL:
    ├─ If TARGET_GOAL = "Education" → "Education Planning"
    ├─ If TARGET_GOAL = "Marriage" → "Marriage Planning"
    ├─ If TARGET_GOAL = "Health" → "Healthcare"
    ├─ If TARGET_GOAL = "Wellness" → "Wellness Savings"
    └─ Else use descriptive category from document
    
    Special: Check product name for specifics (Endowment, Multipurpose, etc.)

20. REWARD_TYPE
    Max 30 chars: "Points", "Cashback", "Profit", "Bonus", "Vitality Points" | N/A

21. CURRENCY
    Max 30 chars: "PKR", "PKR + FCY", "USD" | N/A

22. CURRENCY_TYPE
    EXACTLY: "PKR" | "FCY" | "PKR + FCY" | "N/A" (FCY = Foreign Currency)

23. MIN_BALANCE
    Number only | N/A if not mentioned

24. AVG_BALANCE_REQUIREMENT
    Number only | N/A if not mentioned

25. MIN_INCOME
    Number only (PKR) | N/A if not mentioned

26. MIN_INCOME_USD
    Number only (USD) | N/A if not mentioned

27. MIN_INVESTMENT
    Number only | N/A if not mentioned

28. MIN_CONTRIBUTION
    Number only (contribution amount) | N/A if not mentioned

29. LOAN_AMOUNT_RANGE
    Max 50 chars | Compact: "200K-3M", "1M-10M" (use K for thousands, M for millions) | N/A

30. COVERAGE_AMOUNT
    Max 50 chars | Compact: "500K-1.75M" or "Bronze: 150K, Silver: 300K, Gold: 500K" | N/A

31. FINANCING_TYPE
    EXACTLY: "Conventional" | "Islamic" | "Takaful" | "Mudarabah" | "N/A"

32. DEPOSIT_PROFIT_TYPE
    ONE value: Variable | Tier-based | Fixed | Bonus-based | Bonus-based & Unit-linked | N/A
    
    DECISION TREE:
    ├─ If health/protection insurance → N/A
    ├─ If mentions "Unit Allocation" / "fund selection" / "invest in funds" → Variable
    ├─ If shows different rates by term (Year 1: 60%, Year 2: 80%) → Tier-based
    ├─ If shows bonus structure + unit-linked → Bonus-based & Unit-linked
    ├─ If only bonus structure → Bonus-based
    ├─ If fixed profit rate → Fixed
    └─ Else for savings plans → Variable (default)
    
    Note: "Unit-linked" is mechanism, "Variable" is type. If unit-linked → Variable

33. DEPOSIT_PROFIT_FREQUENCY
    Max 20 chars: Monthly | Quarterly | Semi-annual | Annual | At Maturity | N/A
    
    CRITICAL: Distinguish from PAYMENT FREQUENCY (how often customer pays)
    
    DECISION:
    ├─ If health/protection insurance → N/A
    ├─ If document says "profit paid at maturity" → At Maturity
    ├─ If document says "annual profit" → Annual
    ├─ If document says "quarterly profit" → Quarterly
    └─ Else if savings/investment plan (no explicit mention) → At Maturity (DEFAULT)
    
    Do NOT confuse "Payment Frequency: Annual" with "Profit Frequency"

34. TENURE
    Max 30 chars | Readable format: "1 year", "10-25 years", "Yearly renewable"

35. TENURE_OPTIONS
    Max 50 chars | Structured: "10, 15, 20, 25 years" or "1M → 5Y" or "Annual, Semi-annual, Quarterly"

36. MIN_TERM_YEARS
    Number only | N/A if not found

37. MAX_TERM_YEARS
    Number only | N/A if not found

38. BUSINESS_TENURE
    Max 30 chars: ">=3 years", "2+ years operating" (for SME/business products) | N/A

39. COLLATERAL_TYPE
    Max 50 chars: "Property Mortgage", "Guarantor Required" (for loan products) | N/A

40. EQUITY_REQUIREMENT
    Max 20 chars: "30%", "20% of property value" (for loan products) | N/A

41. DBR_LIMIT
    Max 20 chars: "<=40%", "<=50%", "60% max" (Debt-to-Burden Ratio) | N/A

42. TRANSACTION_LIMIT
    Max 50 chars: "1M monthly", "5M daily ATM", "100 transactions/month" | N/A

43. SPECIAL_CONDITIONS
    Max 200 chars (STRICT) | Critical info ONLY: Free look period, waiting periods, exclusions, age limits
    
    INCLUDE: "Free 14-day look period", "Waiting period 90 days", "Excludes pre-existing conditions"
    EXCLUDE: Full feature lists, all coverage details, basic terms, verbose explanations
    
    If no special conditions → "N/A"

EXTRACTION WORKFLOW
================================================================================

STEP 1: Identify product type
  └─ Insurance/Takaful/Protection → LEAD_MARKER = IBG, PLAN_TYPE = Insurance
  └─ Bank account/card/loan → LEAD_MARKER = BNK

STEP 2: Extract basic information (name, age, gender, customer type)
  └─ Use clear document sections

STEP 3: Determine TARGET_GOAL (critical for SERVICE_TYPE)
  └─ Check PRODUCT_NAME first, then description, then features

STEP 4: Derive SERVICE_TYPE from TARGET_GOAL
  └─ Use mapping defined in rule #19

STEP 5: Extract TARGET_MARKET section for EMPLOYMENT_TYPE
  └─ Check "Target Market" section explicitly (not just eligibility)

STEP 6: Determine SEGMENT_TIER using decision tree
  └─ Check MIN_CONTRIBUTION thresholds and GENDER

STEP 7: Extract profit/financial parameters
  └─ Distinguish DEPOSIT_PROFIT_FREQUENCY from PAYMENT_FREQUENCY
  └─ For savings plans default DEPOSIT_PROFIT_FREQUENCY = "At Maturity"

STEP 8: Extract special conditions (CONCISE, max 200 chars)
  └─ Critical info only, not full feature lists

STEP 9: Validate all fields
  └─ No null values (use "N/A")
  └─ GENDER is exactly: "All" | "Male" | "Female" | "N/A"
  └─ Numeric fields have NO text
  └─ Character limits enforced
