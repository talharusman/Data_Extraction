AH1. PRODUCT_NAME: MUST be extracted from THIS document's own heading or title

     mistakes to AVOID:

     - When in doubt, check WHO UNDERWRITES: if document mentions bank name
       only (Bank Alfalah, HBL, UBL, etc.) → BNK. If document mentions
       insurance company (IGI, EFU, Alfalah Insurance, etc.) → IBG.

     COVERAGE_AMOUNT, OPTIONAL_RIDERS, PREMIUM_PAYMENT_FREQUENCY,

     ALL of these must be "N/A" for loans.

     COLLATERAL_TYPE if collateral is mentioned.

     FINANCING_TYPE as "Conventional" or "Islamic" only (never "Unit Linked").

AH5. Every extracted field must correspond to EXPLICIT text in THIS document.
     If you cannot find it, return "N/A". Never infer, assume, or hallucinate.

AH6. Do NOT confuse PRICING_RATE with MIN_CONTRIBUTION:
     - PRICING_RATE: For LOAN products ONLY. Interest rates, markup rates,
       KIBOR margins (e.g. "1 Year KIBOR + 3%"). For insurance → "N/A".
     - MIN_CONTRIBUTION: For INSURANCE products ONLY. Premium amounts or
       tiered premiums (e.g. "Bronze:5000 | Silver:10000"). For loans → "N/A".

     - Count every item carefully

     - Do NOT abbreviate or summarize the list
     - If multiple customer segments have different docs, merge all with segment labels

     If NO document list exists in source document, return "N/A" — do NOT use a 
     default template or copy from another product. This is critical.

AH8. KEY_BENEFITS (Insurance): List EVERY named benefit/coverage explicitly mentioned.

     If the document says "Accidental Death, ATM Theft, Medical", extract exactly

     For BNK (loan) products: Extract only benefits explicitly stated in THIS

AH9. KEY_EXCLUSIONS (Insurance): Extract ONLY if a formal "Exclusions", "Not Covered",
     or "Limitations" section exists in the document. Never infer exclusions from
     benefit descriptions. If not formally stated, return "N/A".

AH10. CUSTOMER_TYPE: Extract the EXACT customer categories mentioned in eligibility
      sections. Never expand to enum defaults. If doc says "SMEs and Individuals",
      extract "SME | Individual", NOT "SME | Corporate | Retail | Entrepreneur".

===VALIDATION RULES===
V1. If LEAD_MARKER = "BNK" (bank-direct loan/account/card):
    - MUST set these to "N/A": COVERAGE_AMOUNT, MIN_CONTRIBUTION, FREE_LOOK_PERIOD_DAYS,
      OPTIONAL_RIDERS, PREMIUM_PAYMENT_FREQUENCY, KEY_EXCLUSIONS
    - MUST set: LOAN_AMOUNT_RANGE (if loan mentioned), FINANCING_TYPE (Conventional/Islamic), 
      PRICING_RATE (if interest rates stated)
    - If any insurance field is non-N/A for BNK, reject and re-extract

V2. If LEAD_MARKER = "IBG" (insurance/takaful):
    - MUST set: COVERAGE_AMOUNT, MIN_CONTRIBUTION, PREMIUM_PAYMENT_FREQUENCY
    - MUST set: FREE_LOOK_PERIOD_DAYS (or "N/A" if not stated)
    - If LOAN_AMOUNT_RANGE is non-N/A, reject — insurance products don't have loan amounts

V3. MIN_TERM_YEARS and MAX_TERM_YEARS:
    - Extract ONLY if document explicitly states minimum/maximum tenure
    - "Up to 10 years" means MAX_TERM_YEARS=10, MIN_TERM_YEARS="N/A" (not 1)
    - Never default to 1 or 0 without explicit statement
    - For yearly-renewable insurance, MAX_TERM_YEARS=1 is correct (single annual term)

V4. PRODUCT_VARIANT_TIER and MIN_CONTRIBUTION:
    - These MUST have the SAME number of pipe-separated items when BOTH are present
    - If tier table has 4 tiers (Bronze|Silver|Gold|Platinum), 
      MIN_CONTRIBUTION must have exactly 4 amounts (5K|10K|15K|20K)
    - If table shows 4 rows, extract all 4 tiers (never skip the last one like Platinum)

V5. PRICING_RATE (Loans) vs MIN_CONTRIBUTION (Insurance):
    - For loans: PRICING_RATE holds interest/markup rates (e.g. "KIBOR+3%")
    - For insurance: MIN_CONTRIBUTION holds premium amounts (e.g. "5000")
    - These are MUTUALLY EXCLUSIVE per product type
    - BNK products should never have MIN_CONTRIBUTION non-N/A
    - IBG products should never have PRICING_RATE non-N/A

===GLOBAL RULES===

G6. Extract each field from THIS product's own section only. Never copy
    values across products in the same document, and never let a similarly

    Use "N/A" only when the document gives no eligibility/customer

G8. PRODUCT_NAME: Title Case always ("Alfalah Green Energy" not "ALFALAH GREEN

  REQUIRED_DOCUMENTS: "N/A" (if not listed in document — do NOT hallucinate)

===DO NOT===
× PRODUCT_NAME that doesn't appear in the document heading/title.
× Inventing product names like "Jubilee Kamil" when the actual title is "Alfalah Nighaban".
× LEAD_MARKER="IBG" for ANY bank loan product (financing, overdraft, credit
  facility). Loans are BNK only.
× PLAN_TYPE="Insurance" for a loan. Use "Loan", not "Insurance".
× FINANCING_TYPE="Unit Linked" or "Hybrid" for a loan product. Bank loans are
  "Conventional" or "Islamic" only.
× Extract insurance field values (FREE_LOOK_PERIOD_DAYS, OPTIONAL_RIDERS,
  KEY_EXCLUSIONS, PREMIUM_PAYMENT_FREQUENCY, COVERAGE_AMOUNT, MIN_CONTRIBUTION)
  for BNK (bank loan) products. These must be "N/A".
× COVERAGE_AMOUNT or MIN_CONTRIBUTION for non-insurance products.
× MAX_AGE = attained age when entry age is separately stated.
× Using ";" as a list separator (use " | " everywhere).
× Skipping trailing products in multi-product documents.
× Confusing PRICING_RATE with LOAN_AMOUNT_RANGE or EQUITY_REQUIREMENT.
× Hallucinating PROVIDER_NAME as an insurance company for a loan product.
× Hallucinating LOAN_AMOUNT_RANGE, COLLATERAL_TYPE, EQUITY_REQUIREMENT for
  insurance products.
× Putting insurance premiums in PRICING_RATE — use MIN_CONTRIBUTION instead.
× Setting PREMIUM_PAYMENT_FREQUENCY to "N/A" when the document explicitly says
  "Annual", "Monthly", "Yearly", "Quarterly".
× Skipping the last tier (Platinum, etc.) in PRODUCT_VARIANT_TIER or MIN_CONTRIBUTION.
× Defaulting MIN_TERM_YEARS to "1" without explicit minimum stated in document.
× Extracting CLAIMS_SERVICE_CONTACT as "N/A" when a phone or email is provided.
× Copying REQUIRED_DOCUMENTS from other products. Extract from THIS document only.
× Adding "life insurance" or "protection coverage" to KEY_BENEFITS if not explicitly
  mentioned in THIS product's benefits section.
× Hallucinating document lists for insurance products when no documentation section exists.
